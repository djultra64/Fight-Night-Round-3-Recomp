# Controls

Open **OPTIONS → GRAPHICS** to choose a controller family and edit the 14 action bindings. Save to keep your changes. Returning without saving discards pending changes.

The port separates logical actions from physical controls. Automatic mode follows the last active device; manual Xbox, PlayStation or Nintendo Switch selection is available when hardware identification is ambiguous. Changing families should update prompts without requiring you to rebuild your mappings.

Face-button positions differ between Nintendo and Xbox. At the default physical positions:

| Position | Xbox | PlayStation | Nintendo Switch |
| --- | --- | --- | --- |
| Bottom | A | Cross | B |
| Right | B | Circle | A |
| Left | X | Square | Y |
| Top | Y | Triangle | X |

Use the displayed action and matching physical position. A logical action must not be inferred from the Xbox letter when using a Nintendo layout. Optional remapping can change which physical control performs an action.

The native footer provides the return action from GRAPHICS to OPTIONS; there is no additional Back row. Follow the displayed return prompt for your controller family and mappings.

If a prompt does not match the action performed, check the selected family and optional bindings. Include the selected family, affected action and displayed prompt when reporting a mismatch.
