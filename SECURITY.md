# Security

Beta software may contain defects. Use verified game inputs and trusted source/build packages. The input hashes validate supported originals; they do not authenticate an arbitrary download or establish its safety.

For an ordinary crash or compatibility issue, follow the [troubleshooting guide](docs/beta/troubleshooting.md). For a suspected security vulnerability, avoid publishing exploit details, personal data or proprietary game material in a public issue. Use the repository's private vulnerability reporting feature if enabled. Otherwise, open an issue requesting a private reporting channel without including sensitive details.

Include the affected version, OS, minimal reproduction and potential impact when a private channel is available. Do not send disc images, XEX files, extracted assets or game-derived dumps. No dedicated response time or security support period is currently promised.
